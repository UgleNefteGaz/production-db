# ENUM-типы

## specification_status

Статус технологической спецификации:

- Draft - черновик;
- Active - действующая;
- Archived - архивная.

## production_order_status

Статус производственного заказа:

- Created - создан;
- Planned - запланирован;
- InProgress - выполняется;
- Completed - завершен;
- Cancelled - отменен.

## production_batch_status

Статус производственной партии:

- Planned - запланирована;
- InProgress - находится в производстве;
- Completed - производство завершено;
- Rejected - партия отклонена;
- Cancelled - партия отменена.

## production_line_status

Состояние производственной линии:

- Active - доступна для производства;
- Maintenance - находится на обслуживании;
- Inactive - не используется.

## batch_operation_status

Статус выполнения технологической операции:

- Planned - запланирована;
- InProgress - выполняется;
- Completed - завершена;
- Cancelled - отменена.

## quality_check_stage

Этап контроля качества:

- Intermediate - промежуточный контроль;
- Final - итоговый контроль.

## quality_check_result

Результат контроля качества:

- Passed - проверка пройдена;
- Failed - проверка не пройдена;
- Conditional - условно принято.

## defect_severity

Критичность производственного дефекта:

- Minor - незначительный;
- Major - существенный;
- Critical - критический.
