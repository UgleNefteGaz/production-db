## 17.09.2026

### Выполнено

- практическое использование `idx_production_orders_status_start` подтверждено через `EXPLAIN ANALYZE`;
- план PostgreSQL показал `Index Scan`, оба поля составного индекса использованы в `Index Cond`;
- добавлен полнотекстовый GIN-индекс `idx_products_fts`;
- полнотекстовый поиск по слову `шампунь` вернул `SH500` и `SH250`;
- на маленькой таблице оптимизатор выбрал `Seq Scan`, поэтому для учебной проверки временно использовалось `SET enable_seqscan = off`;
- после этого подтверждён `Bitmap Index Scan on idx_products_fts`;
- частичный индекс `uq_specifications_one_active_per_product` проверен через `EXPLAIN ANALYZE`;
- PostgreSQL самостоятельно выбрал этот индекс для поиска активной спецификации продукта;
- для дополнительных индексов добавлены `COMMENT ON INDEX`;
- комментарии проверены через системный каталог PostgreSQL;
- документация по индексам переработана для устранения повторов.
