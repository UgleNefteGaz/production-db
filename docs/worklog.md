## Типы данных и JSONB

### Выполнено

- проанализированы фактические типы данных всех колонок основной базы;
- подтверждено, что существующие типы соответствуют назначению данных и не требуют изменения;
- для первичных ключей зафиксирован единый подход `bigint GENERATED ALWAYS AS IDENTITY`;
- для внешних ключей используется совместимый тип `bigint`;
- обоснован отказ от UUID для текущей централизованной модели;
- рассмотрены различия типов `json` и `jsonb`;
- для хранения дополнительных параметров контроля качества выбран тип `jsonb`;
- в таблицу `quality_checks` добавлено поле `measurements jsonb NOT NULL DEFAULT '{}'::jsonb`;
- добавлено ограничение, разрешающее хранить в `measurements` только JSON-объекты;
- физическая схема `db/schema.sql` обновлена;
- логическая модель `db/schema.dbml` обновлена;
- словарь данных `docs/data-dictionary.md` обновлён;
- в `db/seed.sql` добавлены примеры JSONB-данных для различных продуктов;
- создан файл `sql/json.sql` с примерами работы с JSONB;
- практически проверены добавление, выборка, фильтрация и изменение JSONB-данных.

### Проверенные операции JSONB

Проверены:

```text
->          получение значения как jsonb
->>         получение значения как text
?           проверка наличия ключа
@>          проверка содержания JSONB-фрагмента
#>>         получение значения по вложенному пути
jsonb_set() добавление и изменение ключа
-           удаление ключа
```

Также проверены:

- приведение значения JSONB к `numeric`;
- фильтрация по числовым значениям внутри JSONB;
- фильтрация по строковым значениям;
- работа с вложенными JSON-объектами;
- добавление новой записи `quality_checks` с JSONB через `INSERT`;
- защита демонстрационного `INSERT` от повторного создания одной и той же записи через `NOT EXISTS`.

### Результат

Существующая система типов данных сохранена без изменений.

В качестве идентификаторов используется:

```text
Primary Key: bigint GENERATED ALWAYS AS IDENTITY
Foreign Key: bigint
```

Для переменных дополнительных параметров контроля качества добавлено поле:

```sql
measurements jsonb NOT NULL DEFAULT '{}'::jsonb
```

Подробное описание выбора типов данных и примеры SQL-запросов добавлены в `README.md`.

Полный набор практических примеров работы с JSONB находится в `sql/json.sql`.
