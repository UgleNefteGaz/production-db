# Production DB

Учебный проект базы данных для системы учёта и контроля производственных процессов предприятия.

## Назначение

База данных предназначена для учёта:

- выпускаемой продукции;
- сырья и материалов;
- технологических спецификаций;
- производственных заказов;
- производственных партий;
- технологических операций;
- производственных линий;
- сотрудников и смен;
- фактического расхода материалов;
- контроля качества;
- производственного брака.

## СУБД

PostgreSQL

## Структура проекта

- 'db/' - DBML-модель, SQL-схема и тестовые данные;
- 'docs/' - документация и журнал разработки;
- 'sql/' - запросы, представления, функции и триггеры;
- 'images/' - изображения и ER-диаграммы.

## Текущее состояние

Проектирование структуры базы данных и ER-модели.
